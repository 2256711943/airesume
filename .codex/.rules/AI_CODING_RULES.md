# AI_CODING_RULES.md

## 1. 任务边界

- 仅实现 `PRD.md` 明确范围内的功能。
- 接口以 `OPENAPI.yaml` 为准。
- SSE 事件协议以 `API_STREAM_SPEC.md` 为准。

## 2. 决策优先级

1. 产品需求：`PRD.md`
2. 接口契约：`OPENAPI.yaml`
3. 流式协议：`API_STREAM_SPEC.md`
4. 数据模型：`DB_SCHEMA.md` / `schema.prisma`

## 3. 代码变更要求

- 每次改动需说明：变更内容、影响范围、验证结果。
- 未执行测试时必须给出原因。
- 新增公共函数、类、方法前需有简洁的中文注释说明意图。

## 4. 禁止项

- 禁止提交密钥、令牌或敏感数据。
- 禁止绕过 DTO 输入校验。
- 禁止吞掉异常且不返回可读错误信息。
- 禁止保留临时调试代码进入主分支。

## 5. 输出要求（每次 AI 回答至少包含）

- 本次改动内容
- 受影响模块
- 已执行验证
- 剩余风险或后续建议

## 6. 文件编辑策略

- 在非必要情况下，不要删除整个文件后再重写。
- 优先基于原有代码做局部修改，只删除或替换需要变更的部分。
- 只有在整文件重写明显更安全、更简单或能显著降低维护成本时，才允许整文件替换，并需在结果说明中明确原因。

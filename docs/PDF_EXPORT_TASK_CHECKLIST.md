## 使用约定

1. 质量关口：**M1 未达成不进阶段二；M4 未通过不进阶段五**，不可跳过或合并。
2. 每个任务的核验标准需**全部满足**才可勾选，部分满足视为未完成。
3. 涉及接口行为（错误码、超时、响应头）的任务，一律以 [接口契约](./PDF_EXPORT_API_CONTRACT.md) 为准，契约变更需同步更新本表对应核验标准。
4. 阶段核验项通过后，同步在实施计划书的对应里程碑处留痕。

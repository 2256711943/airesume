# 简历 PDF 多模板主题系统可执行任务清单

## 1. 目标

实现“左侧编辑、右侧实时预览、主题色切换、内置模板导出”的 PDF 体验，并与现有 `useResumePdfExport.ts`、`resume-pdf-export.service.ts` 保持兼容。

## 2. 任务拆分

### 2.1 数据层

- 定义 `templateId`、`themeId`、`templateVersion`、`themeVersion`
- 补充模板/主题 manifest
- 约定默认模板和默认主题
- 保留旧导出参数兜底

### 2.2 前端预览层

- 创建右侧实时预览容器
- 接入统一 `resumeData + templateId + themeId`
- 实现主题色切换即时刷新
- 增加预览 debounce

### 2.3 模板系统

- 设计 3 套内置模板
- 定义布局、槽位、页边距、字体层级
- 实现模板切换与缩略图预览

### 2.4 主题系统

- 设计 3 套内置主题
- 定义颜色、字体、间距、边框 tokens
- 支持字号与字体族切换

### 2.5 导出链路

- 扩展导出请求参数
- 后端按模板/主题生成统一 HTML
- 保持超时、重试、错误码机制

### 2.6 质量保障

- 补充预览与 PDF 一致性测试
- 补充长简历分页测试
- 补充不同主题组合的截图对比

## 3. 里程碑

| 阶段 | 交付物             | 预估   |
| ---- | ------------------ | ------ |
| M1   | 数据结构与兼容策略 | 0.5 天 |
| M2   | 模板/主题 manifest | 1.5 天 |
| M3   | 左右分栏实时预览   | 2 天   |
| M4   | 导出链路接入       | 1.5 天 |
| M5   | 测试与修正         | 1.5 天 |

## 4. 验收标准

- 可在编辑区切换主题并即时看到预览变化
- 预览与导出 PDF 在布局和颜色上保持一致
- 旧导出方式仍可工作
- 3 套模板、3 套主题均可正常导出

# IMPLEMENTATION_PLAN.md

## Phase 1（第1-2周）：闭环可用

- 初始化前后端工程骨架（Nuxt + Nest）
- 登录功能（基础）
- 商品手动录入 + CSV 导入
- 非流式生成接口
- SSE 轻量流式生成
- 规则 + LLM 评分
- 一键改写

交付物：

- 可录屏演示的最小闭环系统

## Phase 2（第3-4周）：产品化增强

- 版本对比视图
- 采纳反馈与原因标签
- 指标看板（生成量、评分、采纳率、耗时）
- 失败重试交互

交付物：

- 可讲业务价值与结果指标的版本

## Phase 3（第5-6周）：工程化升级

- 接入 Redis + BullMQ（生成/评分异步化）
- 请求链路可观测（Langfuse）
- 错误归因报表
- 评测集与回归评估

交付物：

- 可讲系统稳定性与工程深度的版本

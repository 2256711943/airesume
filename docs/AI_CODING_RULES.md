# AI_CODING_RULES.md

本文件是给 AI coding 的硬约束规则。

## 1. 任务边界

- 只实现 PRD 中明确列出的功能。
- 不得添加未批准第三方依赖。
- 不得重命名已有 API 字段或 SSE 事件名。

## 2. 决策规则

- 业务规则冲突：以 `PRD.md` 为准。
- 接口冲突：以 `OPENAPI.yaml` 为准。
- 流式协议冲突：以 `API_STREAM_SPEC.md` 为准。
- 数据结构冲突：以 `DB_SCHEMA.md` / `schema.prisma` 为准。

## 3. 代码提交要求

- 每次改动必须包含：
  - 变更说明
  - 影响范围
  - 测试结果
- 若未完成测试，必须明确写“未执行原因”。

## 4. 禁止事项

- 禁止直接修改生产配置模板中的密钥位。
- 禁止跳过输入校验。
- 禁止吞掉异常不记录。
- 禁止将临时调试代码提交到主分支。

## 5. 输出格式（每次 AI 回答至少包含）

- 本次改动内容
- 受影响模块
- 已执行测试
- 未覆盖风险

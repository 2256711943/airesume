ai简历1
项目描述
基于 Nuxt4（Vue3 + Vite + TypeScript + Element Plus）+ NestJS（Prisma + SQLite）全栈架构开发的 AI 简历生成助手，实现简历生成，与生成过程实时可视化及过程追踪运行记录回放、上下文与记忆管理、历史会话恢复、简历编辑联动实时预览、简历多模板 PDF 导出等核心功能。
项目亮点

1. 自研 SSE 分帧渲染管线，实现打字机效果，背压控制：以构建 "Ingress → 转换 → 帧缓冲 → 逐帧提交" 渲染引擎，8ms 帧预算 + EWMA 帧耗时平滑，四维加权压力评分（队列深度/滞留时长/帧耗时超标/连续积压）驱动 idle~critical 五级降级（裁剪装饰性帧项、压缩帧预算至 1ms），高峰期帧耗时稳定在预算内、FPS 保持 ~60，长任务（>16ms）出现频率下降约 80%；打字机压力高时降速、遇终止项立即冲刷，降级不丢内容；以状态机统一管理 SSE 生命周期，超时检测 + 自动重试保证全程可中断、可恢复、可追踪，一次约 10 分钟 / 3 万字长流无中断、无丢失。2.落地分层上下文与记忆管理:采用四级渐进式压缩与 pack 缓存按 usageRatio 触发,摘要分写入侧/读取侧双轨,用户偏好记忆跨会话归档，保证跨会话保留用户长期画像,引入遗忘曲线自动降权；tiktoken 精确估算 token;每次构建记录 selectedMemoryIds、7 类裁剪原因与 token 统计,全程可审计,最终压缩率约 70%、单轮成本下降 60%,20 轮长会话记忆命中率 90%+。
2. 构建 Agent 链路观测、回放与故障诊断闭环：实时观测端提供运行时间线、span 树、工具调用状态，支撑 "边运行边排障"；SSE 断线重连后基于 seq 做事件补偿，保证数据连续可追；回放层基于 seq 与 checkpoint 锚点实现已完成 run 的单步播放、暂停、快进与定位，并支持多 run 对比定位决策差异；诊断采用规则引擎优先，并可回指事件证据，同时预留 LLM 辅助诊断接口。
3. 简历 PDF 导出服务，前端以 "模板 + 主题" 双维度解耦构建多模板设计系统，新增模板或主题仅追加一条配置；前端预览与后端导出共用同一份渲染数据与 HTML/CSS 单一渲染源，从架构上消除 "双实现" 导致的预览与导出一致性偏差；配套编辑联动实时预览，切换模板/主题即时重绘。

项目描述：基于 Vue3 + Vite + TypeScript 开发的CRM 客户关系管理系统，采用 Pinia 状态管理 + Element Plus UI 组件库，实现客户管理、销售漏斗拖拽、数据导出（分片上传+断点续传）、前端监控等核心功能，并通过大库懒加载、手动分块策略等手段进行性能优化。

1. 主导搭建导出任务中心，将导出从页面逻辑升级为状态机任务流（pending/running/success/failed/cancelled），支持失败重试、幂等复用（相同参数任务复用）与任务追踪，降低重复导出与误操作成本。  
2. 重构大数据导出链路：采用“分页分片 + 断点续跑 + 自动重试（指数退避+抖动）”，基于 IndexedDB 持久化 checkpoint，并用 Web Worker 处理 CSV 生成（失败自动降级兜底），提升长任务稳定性与页面可用性。  
3. 设计客户状态流转规则引擎：将“潜客-跟进-成交/流失”等状态迁移约束抽离为可校验规则，前端落地乐观更新 + 失败回滚，保证状态变更的业务一致性与可恢复性。  
4. 治理 CRM 列表高并发查询：引入 AbortController 取消过期请求、requestId 时序保护防止旧响应覆盖新结果，并结合请求去重，解决高频筛选/翻页下的数据回跳与竞态问题。  
5. 实现列表性能优化方案：落地 TTL + LRU 数据缓存、下一页预取与批量 patch 刷新策略，减少重复请求与渲染抖动，提升复杂筛选场景的响应速度和交互流畅度。  
6. 建立业务可观测与交付保障体系：围绕客户查询、状态变更、导出等关键链路埋点，统一采集 API 耗时/成功率/状态码及前端异常并做去重告警；同时推进核心依赖分包与 CI 质量门禁（lint/类型/单测/E2E/覆盖率），提升线上问题定位效率，保障 CRM 核心流程稳定交付。

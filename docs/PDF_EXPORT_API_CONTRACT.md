# PDF 导出接口契约（前后端联调依据）

> 本契约是 `PDF_EXPORT_IMPLEMENTATION_PLAN.md` 阶段二"接口契约确认"的落地文档，前后端按此约定并行开发。
> 对应决策：服务端无头浏览器渲染 / 前端打印视图组件序列化 DOM / 同步即点即下 / 本地先行部署后置。

## 1. 接口总览

| 项       | 约定                                                            |
| -------- | --------------------------------------------------------------- |
| 接口路径 | `POST /resume/export-pdf`                                       |
| 请求格式 | `application/json`                                              |
| 成功响应 | `200 OK`，`application/pdf` 二进制文件流                        |
| 失败响应 | 非 200 状态码 + `application/json`（复用现有 ApiResponse 结构） |
| 交互形态 | 同步：请求发出后等待响应，响应即最终结果                        |
| 认证     | 沿用现有 JWT 认证，需携带登录态                                 |
| 幂等性   | 不要求幂等（每次请求独立生成新 PDF）；重复点击由前端防抖控制    |

## 2. 请求契约

### 2.1 请求头

| Header          | 值                                | 说明                         |
| --------------- | --------------------------------- | ---------------------------- |
| `Content-Type`  | `application/json; charset=utf-8` | 请求体为 JSON                |
| `Authorization` | `Bearer <token>`                  | 现有认证体系，与其它接口一致 |

### 2.2 请求体字段

| 字段       | 类型   | 必填 | 说明                                                                                       |
| ---------- | ------ | ---- | ------------------------------------------------------------------------------------------ |
| `html`     | string | 是   | 前端打印视图组件序列化后的完整 HTML（含内联样式）                                          |
| `fileName` | string | 否   | 期望下载文件名（不含扩展名，如 `resume-technical-v1`）；缺省由服务端生成 `resume-<时间戳>` |
| `options`  | object | 否   | 导出参数，缺省使用默认值，见下表                                                           |

### 2.3 options 字段

| 字段                  | 类型    | 默认值                                                         | 说明                                                       |
| --------------------- | ------- | -------------------------------------------------------------- | ---------------------------------------------------------- |
| `format`              | string  | `'A4'`                                                         | 页面尺寸，本期仅支持 `A4`                                  |
| `margin`              | object  | `{ top: '20px', right: '20px', bottom: '20px', left: '20px' }` | 页边距，支持 `top/right/bottom/left` 四向                  |
| `printBackground`     | boolean | `true`                                                         | 是否打印背景色/背景图，简历样式需要保留背景时保持开启      |
| `preferCSSPageSize`   | boolean | `true`                                                         | 优先遵循 HTML 内 `@page` 规则（页面尺寸与边距以 CSS 为准） |
| `displayHeaderFooter` | boolean | `false`                                                        | 是否显示页眉页脚（配合下两项使用）                         |
| `headerTemplate`      | string  | `''`                                                           | 页眉模板，纯 HTML 片段，样式需全部内联                     |
| `footerTemplate`      | string  | `''`                                                           | 页脚模板，纯 HTML 片段，样式需全部内联                     |

### 2.4 输入约束

| 约束项             | 约定                                                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------------------------------------- |
| `html` 大小上限    | ≤ 500 KB（简历打印视图实测远小于此，超限返回 `PDF_PAYLOAD_TOO_LARGE`）                                                |
| `options` 大小上限 | ≤ 4 KB                                                                                                                |
| HTML 内容要求      | 样式必须内联或随 HTML 完整传递；**不允许依赖服务端无法访问的网络资源**（外链字体、外链图片、外链 CSS 一律不保证加载） |
| 内容非空           | `html` 去除空白后必须包含可渲染内容，否则返回 `PDF_EMPTY_CONTENT`                                                     |

## 3. 响应契约

### 3.1 成功响应（200）

| 响应项                | 约定                                                                            |
| --------------------- | ------------------------------------------------------------------------------- |
| `Content-Type`        | `application/pdf`                                                               |
| `Content-Disposition` | `attachment; filename="<fileName>.pdf"`（文件名取请求 `fileName` 或服务端缺省） |
| `X-Pdf-Page-Count`    | 自定义响应头，返回实际页数（供前端展示与阶段四校验）                            |
| Body                  | PDF 文件二进制流                                                                |

前端行为：以 Blob 接收，按 `Content-Disposition` 中的文件名触发浏览器下载。

### 3.2 失败响应（非 200 + JSON）

统一复用现有 ApiResponse 结构（与 `apps/api/src/common/api-response.ts` 保持一致）：

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "PDF_RENDER_TIMEOUT",
    "message": "PDF 渲染超时，请稍后重试"
  },
  "requestId": "req_xxxxx"
}
```

## 4. 错误码约定

| 错误码                    | HTTP 状态码 | 触发场景                                         | 前端建议处理                                        |
| ------------------------- | ----------- | ------------------------------------------------ | --------------------------------------------------- |
| `PDF_INVALID_INPUT`       | 400         | 请求体缺失 / 字段类型错误 / 必填项为空           | 提示"导出参数有误，请刷新后重试"                    |
| `PDF_PAYLOAD_TOO_LARGE`   | 413         | `html` 或 `options` 超过大小上限                 | 提示"内容过大，无法导出"                            |
| `PDF_EMPTY_CONTENT`       | 422         | HTML 无可渲染内容                                | 提示"简历内容为空，无法导出"                        |
| `PDF_RENDER_TIMEOUT`      | 504         | 渲染超过服务端约定超时（45s）                    | 提示"导出超时，请点击重试"；可自动重试 1 次         |
| `PDF_RENDER_FAILED`       | 500         | 渲染过程异常 / 浏览器进程异常                    | 提示"导出失败，请稍后重试"；记录 requestId 便于排查 |
| `PDF_FONT_NOT_READY`      | 422         | 字体加载失败（中文字体未就绪）                   | 提示"字体加载失败，请重试"；可自动重试 1 次         |
| `PDF_BROWSER_UNAVAILABLE` | 503         | 浏览器实例不可用（未就绪 / 已崩溃 / 并发超限）   | 提示"导出服务繁忙，请稍后再试"                      |
| `PDF_DOWNLOAD_FAILED`     | 500         | PDF 文件流生成后写出失败（极少见，保留用于兜底） | 提示"下载失败，请重试"                              |

## 5. 等待规则与超时约定

| 项             | 约定                                                                                                             |
| -------------- | ---------------------------------------------------------------------------------------------------------------- |
| 服务端渲染超时 | 45 秒（超时返回 `PDF_RENDER_TIMEOUT`，服务端必须终止对应渲染任务，不留悬挂进程）                                 |
| 前端请求超时   | 60 秒（比服务端超时宽裕，保证能收到服务端的超时错误响应）                                                        |
| 前端防重复     | 导出中状态禁用导出按钮（已写入实施计划书阶段三）                                                                 |
| 重试策略       | 失败允许重试，建议最多 2 次；`PDF_RENDER_TIMEOUT` / `PDF_FONT_NOT_READY` 可自动重试 1 次，其余错误由用户手动重试 |
| 并发           | 服务端单次导出占用一个浏览器会话；并发超限时按 `PDF_BROWSER_UNAVAILABLE` 返回（实施计划书阶段二实现并发控制）    |

## 6. 传输与安全约定

| 项       | 约定                                                                                                                    |
| -------- | ----------------------------------------------------------------------------------------------------------------------- |
| 认证     | 沿用现有 JWT 认证与 `requestId` 中间件（失败响应带 requestId，便于日志关联）                                            |
| 内容安全 | 服务端仅将 `html` 作为静态内容交给无头浏览器渲染；**不执行服务端模板注入**，前端传入即视为已消毒的展示内容              |
| 资源加载 | 无头浏览器渲染期间禁止访问内网/外网地址的约束由服务端配置控制（阶段一验证结论落在此处）；前端应保证打印视图资源全部内联 |
| 日志     | 每次导出记录：requestId、耗时、页数、结果（成功/错误码），接入现有可观测体系                                            |

## 7. 请求示例（HTTP）

```
POST /resume/export-pdf
Authorization: Bearer <token>
Content-Type: application/json

{
  "html": "<!doctype html><html><head><style>...</style></head><body>...</body></html>",
  "fileName": "resume-technical-v1",
  "options": {
    "format": "A4",
    "printBackground": true,
    "displayHeaderFooter": true,
    "headerTemplate": "<div style=\"font-size:9px;text-align:center;\">张三 · 后端工程师</div>",
    "footerTemplate": "<div style=\"font-size:9px;text-align:center;\"><span class=\"pageNumber\"></span> / <span class=\"totalPages\"></span></div>"
  }
}
```

## 8. 前端配合约束（打印视图组件）

- 打印视图组件序列化时，取根节点 `outerHTML` 作为 `html` 字段；样式必须内联进节点，不能依赖运行时注入或外链。
- 序列化前确保字体已加载完成（浏览器字体加载 API 就绪后再序列化，避免导出缺字）。
- 下载文件名优先使用服务端 `Content-Disposition` 返回值，前端不自行拼接。

## 9. 本期不做（边界声明）

- 不做异步任务 / render job 状态追踪（实施计划书已明确为后续阶段）。
- 不做页数、文本完整性的服务端强制校验（阶段四引入校验体系，本期仅通过 `X-Pdf-Page-Count` 头预留页数上报）。
- 不做多模板、批量导出、导出历史记录。

## 10. 契约变更流程

- 任何字段增删、错误码调整、超时变更，需前后端同步更新本契约文档并确认后再实施。
- 契约变更需记录日期、变更内容、影响方。

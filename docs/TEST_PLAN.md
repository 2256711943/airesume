# TEST_PLAN.md

## 1. 测试范围

- 认证模块
- 简历信息输入与参数校验
- 简历生成（非流式）
- 简历生成（SSE，后续阶段）

## 2. 测试层级

1. 单元测试
- Service 业务逻辑
- Prompt 构造与响应解析
- 结构化输出校验与兜底逻辑

2. 集成测试
- API 与数据库交互
- 认证后权限隔离
- resume 生成链路

3. E2E 测试
- 登录 -> 输入简历信息 -> 生成简历 -> 查看结构化结果

## 3. SSE 专项测试

- 正常事件序列：`start -> (progress|chunk)* -> done`
- 异常事件序列：`start -> (progress|chunk)* -> error`
- 客户端中断处理
- 多并发连接稳定性（本地基线）

## 4. 验收数据集

- 至少 20 条简历样本（覆盖校招/社招/转岗）
- 每条至少生成 3 个版本

## 5. DoD（完成定义）

- 功能通过：简历生成核心链路可复现
- 质量通过：结构化输出成功率 >= 95%
- 性能通过：3版本生成 P95 < 15s
- 文档通过：接口、协议、数据模型与实现一致

# TEST_PLAN.md

## 1. 测试范围

- 认证模块
- 商品录入与 CSV 导入
- 文案生成（非流式 + SSE）
- 文案评分
- 定向改写
- 采纳反馈

## 2. 测试层级

1. 单元测试
- Service 业务逻辑
- 评分计算函数
- Prompt 构造与响应解析

2. 集成测试
- API 与数据库交互
- 认证后权限隔离
- copy 相关完整链路

3. E2E 测试
- 登录 -> 录入商品 -> 流式生成 -> 评分 -> 改写 -> 采纳

## 3. SSE 专项测试

- 正常事件序列：`chunk* -> done`
- 异常事件序列：`chunk* -> error`
- 客户端中断处理
- 多并发连接稳定性（本地基线）

## 4. 验收数据集

- 至少 20 条商品样本（覆盖不同品类）
- 每条至少生成 3 个版本

## 5. DoD（完成定义）

- 功能通过：核心链路可复现
- 质量通过：结构化输出成功率 >= 95%
- 性能通过：3版本生成 P95 < 15s
- 文档通过：接口、协议、数据模型与实现一致

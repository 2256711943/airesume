## 0. 决策记录（已与需求方确认）

| 决策项   | 结论               | 说明                                                                            |
| -------- | ------------------ | ------------------------------------------------------------------------------- |
| 实现方案 | 方案 A             | 独立打印视图组件，预览与序列化共用同一棵 DOM                                    |
| 预览形态 | 内嵌常显           | 版本预览区下方直接展示当前选中版本的打印视图                                    |
| 页眉页脚 | 文档流内区块       | `displayHeaderFooter=false`，页眉（姓名+目标岗位）/页脚（页码占位）写在 HTML 内 |
| 文件命名 | 与 Markdown 同名   | 复用 `buildVariantFileName` 结果，去掉 `.md` 后缀                               |
| 导出并发 | 全局单飞           | 同一时刻仅允许一个导出任务，导出中禁用 PDF 入口                                 |
| 样式传递 | `outerHTML` 序列化 | 组件根节点内包含 `<style>` 元素，随 DOM 一并传递；类名统一 `rpv-` 前缀隔离      |
| 字体就绪 | 序列化前等待       | `document.fonts.ready` 等待，带 10s 兜底超时，超时继续不阻塞                    |

## 1. 范围与目标

对应核验表 T3.1~T3.5，目标是：**打印视图组件与「导出 PDF」入口上线（本地环境），端到端"点击导出 → 下载完成"可用**，且既有「导出 Markdown」不受影响。

## 2. 边界条件约定（默认决策）

| 边界                  | 约定行为                                                                             |
| --------------------- | ------------------------------------------------------------------------------------ |
| 无选中版本 / 内容为空 | 「导出 PDF」按钮禁用（与「导出 Markdown」同条件：`selectedVariantMarkdown` 为空）    |
| 导出中防重复          | 全局导出锁：导出期间 PDF 按钮禁用并显示「导出中…」，不可再次触发                     |
| 前端请求超时          | 60s（宽于服务端 45s，保证能收到服务端错误响应）                                      |
| 自动重试              | 仅 `PDF_RENDER_TIMEOUT` / `PDF_FONT_NOT_READY` 自动重试 1 次；其余错误由用户手动重试 |
| 文件名兜底            | `Content-Disposition` 解析失败时，回退用前端传入文件名                               |
| HTML 大小             | 不引入前端预警（500KB 上限远大于实际体量）                                           |
| 样式隔离              | 打印视图类名全部 `rpv-` 前缀，样式只在组件根节点内生效，不污染聊天界面               |
| 数据快照              | 发起导出那一刻取当前 `selectedVariant` 与 `form` 值，避免导出中状态漂移              |
| 卸载清理              | 页面卸载时重置导出中状态（`onBeforeUnmount`）                                        |

## 3. 分步任务

### 步骤 1：打印样式基线（独立常量文件）

**做什么**

- 新增打印视图专用样式常量文件，集中管理打印视图的全部 CSS。
- 样式以字符串常量导出，供组件在根节点内渲染 `<style>` 元素（随 `outerHTML` 序列化）。

**设计要点**

- 页面尺寸：`@page` 定义 A4，边距与契约默认一致（四周 20px）。
- 排版固定值：字号、行距、段落间距、区块间距一律用固定 `px` 值定义，避免预览与 PDF 偏差。
- 分页友好：经历/项目条目、技能区块使用分页保护规则（避免条目跨页截断）。
- 页眉页脚：定义页眉（姓名 + 目标岗位）与页脚（页码占位）区块样式。
- 隔离：全部选择器以 `rpv-` 前缀开头。
- 资源：不得引用任何外链字体/图片/CSS，字体使用系统字体栈（覆盖中英文）。

**涉及文件**

- 新增：`apps/web/utils/resume-print-style.ts`

**验收标准**

- [ ] 样式常量独立文件可被组件引用
- [ ] 含 A4 `@page` + 20px 四周边距规则
- [ ] 关键排版（字号/行距/间距）全部为固定值
- [ ] 含分页保护规则与页眉页脚占位样式
- [ ] 全部选择器 `rpv-` 前缀，无外链资源引用

### 步骤 2：打印视图组件

**做什么**

- 新增独立打印视图组件，props 接收简历数据（版本数据 + 姓名 + 目标岗位）。
- 渲染结构：页眉（姓名 · 目标岗位）→ 个人总结 → 工作经历 → 项目经历 → 核心技能 → 页脚占位。
- 组件根节点内包含 `<style>` 元素（内容来自步骤 1 常量），序列化时随 `outerHTML` 一起带走。
- 对外暴露根节点引用，供导出时取 `outerHTML`。

**设计要点**

- 预览与序列化必须共用同一棵 DOM（同一模板渲染），保证所见即所得。
- 空数据占位：summary / experience / projects / skills 为空时渲染占位文案，不输出空白区块。
- 样式与聊天界面完全隔离（`rpv-` 前缀 + 组件内自包含样式）。
- 分页友好结构：区块级布局，避免长列表导致整段跨页。

**涉及文件**

- 新增：`apps/web/components/resume/PrintResumeView.vue`

**验收标准**

- [ ] 独立于聊天界面的简历呈现布局
- [ ] 含页眉页脚占位与分页友好结构
- [ ] 与既有聊天界面样式隔离、互不影响（无全局样式污染）
- [ ] 根节点 `outerHTML` 包含完整内容与 `<style>`，可直接交给导出接口
- [ ] 空数据字段有占位文案

### 步骤 3：PDF 导出工具函数

**做什么**

- 新增 PDF 导出工具，封装完整导出流程：
  1. 序列化前等待字体就绪（`document.fonts.ready`，10s 兜底）；
  2. 携带 JWT 以原生 `fetch` 调用 `POST /resume/export-pdf`（60s 超时，接收 Blob 响应）；
  3. 解析响应头 `Content-Disposition` 获取下载文件名（失败回退前端传入名）；
  4. 触发浏览器下载（Blob + 临时 `<a download>`，用后回收）；
  5. 失败响应按契约错误码映射为可读中文提示；`PDF_RENDER_TIMEOUT` / `PDF_FONT_NOT_READY` 自动重试 1 次。
- 返回结构化结果（成功/失败 + 错误码 + 文件名），供页面展示与交互。

**设计要点**

- 不依赖现有 `useApiFetch`（其面向 JSON 信封），独立实现带 `Authorization` 头与 Blob 响应的请求。
- 失败时优先解析 JSON 信封中的 `error.code`，无法解析时兜底为通用失败。
- 导出中回调（开始/结束）交由页面控制，工具本身只负责请求与下载。

**涉及文件**

- 新增：`apps/web/utils/resume-pdf-export.ts`

**验收标准**

- [ ] 成功路径：按 `Content-Disposition` 文件名触发下载，无手动拼接文件名
- [ ] 各错误码（`PDF_INVALID_INPUT` / `PDF_PAYLOAD_TOO_LARGE` / `PDF_EMPTY_CONTENT` / `PDF_RENDER_TIMEOUT` / `PDF_FONT_NOT_READY` / `PDF_BROWSER_UNAVAILABLE` / `PDF_RENDER_FAILED`）映射提示正确
- [ ] 超时 / 字体错误自动重试恰好 1 次，其余错误不自动重试
- [ ] 字体等待有兜底超时，不无限阻塞
- [ ] 请求超时 60s 生效

### 步骤 4：页面接入与导出交互

**做什么**

- 在版本预览区（`resume.vue` 的「三版预览」区块）下方挂载打印视图组件，内嵌常显展示当前选中版本。
- 在「复制当前版本 / 导出 Markdown」操作区新增「导出 PDF」按钮，两者并列、职责区分。
- 实现导出状态机（全局单飞）：
  - 点击「导出 PDF」→ 进入导出中状态（按钮禁用 + 文案「导出中…」+ 状态横幅提示）；
  - 成功 → 触发下载 + 成功提示（含页数，来源 `X-Pdf-Page-Count`）；
  - 失败 → 按错误码显示可读提示，按钮恢复，保留重试入口（自动重试逻辑在步骤 3 内完成）。
- 挂载/卸载生命周期：卸载时重置导出状态，避免残留。

**设计要点**

- 导出数据快照：点击瞬间取当前 `selectedVariant` + `form` 的姓名/目标岗位，组装序列化 HTML。
- 序列化前确保字体就绪（调用步骤 3 工具的前置逻辑）。
- 「导出 Markdown」的既有逻辑（`exportContent`）与按钮完全不动，仅新增并列按钮。
- 状态反馈复用现有 `statusMessage` 横幅机制，不引入新的全局组件。

**涉及文件**

- 修改：`apps/web/pages/resume.vue`

**验收标准**

- [ ] 「导出 PDF」入口接入版本预览区，与「导出 Markdown」并列且职责清晰
- [ ] 点击导出 → 下载完成全流程顺畅
- [ ] 导出中按钮禁用、防重复点击生效
- [ ] 失败场景展示可读错误信息，重试入口可用
- [ ] 既有「导出 Markdown」行为不受影响
- [ ] 打印视图预览常显于版本预览区，切换版本实时更新

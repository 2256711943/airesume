# PRD.md

## 1. 项目定位

项目名：AI运营内容助手（电商营销文案）  
目标用户：电商运营、内容运营、学生项目演示者  
核心价值：降低文案产出成本，提升文案质量与可复用性

## 2. 核心场景

用户输入商品信息（品类、卖点、受众、平台风格、禁用词）后，系统生成多版本营销文案，并给出评分、改写建议，用户可采纳最佳版本并记录反馈。

## 3. MVP 功能范围（In Scope）

- 账号登录（基础）
- 商品信息手动录入
- CSV 导入商品
- SSE 流式文案生成（3-5 版本）
- 文案评分（规则 + LLM）
- 按问题点改写
- 版本对比 + 采纳反馈
- 基础指标看板

## 4. 非目标（Out of Scope）

- 真实电商开放 API 接入
- 多组织复杂权限
- 自动投放与广告平台直连
- 多语言国际化

## 5. 关键业务指标

- 结构化生成成功率 >= 95%
- 平均评分较初稿改写后提升
- 用户采纳率（adoption_rate）可追踪
- 3 版本生成 P95 < 15s（本地正常网络）

## 6. 验收标准

- 20 条样本商品能稳定跑通闭环
- SSE 页面可实时展示生成过程
- 失败任务有可读错误信息与重试入口
- 接口与文档一致，测试可复现

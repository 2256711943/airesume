# PRD.md

## 1. 项目定位

项目名：AI 简历助手（AI Resume Assistant）  
目标用户：求职者、转岗用户、应届生、技术项目演示者  
核心价值：快速产出结构化简历初稿，提升岗位匹配度与表达质量

## 2. 核心场景

用户输入个人经历（教育、工作、项目、技能）与目标岗位信息后，系统生成结构化简历内容（摘要、经历要点、项目亮点、技能模块），并支持后续迭代优化。

## 3. MVP 功能范围（In Scope）

- 账号登录（基础）
- 简历信息手动录入（表单或粘贴文本）
- 目标岗位输入（岗位名称、岗位描述、行业方向）
- 一键生成结构化简历（V1 必做）
- 生成结果可读展示（分区块）
- 基础失败重试与错误提示

## 4. 非目标（Out of Scope）

- 自动投递到招聘平台
- PDF/Word 高保真排版导出
- 多组织协作权限系统
- 多语言国际化

## 5. 关键业务指标

- 结构化生成成功率 >= 95%
- 生成首稿 P95 < 15s（本地正常网络）
- 关键字段覆盖率 >= 95%（摘要/经历/项目/技能）
- 可复现率：同输入下结构稳定可解析

## 6. 验收标准

- 20 条样本用户画像可稳定生成简历
- 简历输出为结构化数据，可被前端稳定渲染
- 失败任务有可读错误信息与重试入口
- 接口与文档一致，测试可复现

## 7. 迁移原则

- 文档先行，代码后移
- 新能力统一落在 `resume/*` 路由
- 旧的电商文案能力已下线，项目仅保留简历助手主链路

# 代码讲解技能

当用户需要理解、解释或分析代码时使用此技能。

## 使用场景

- 用户选中代码并要求讲解
- 用户询问某个函数/类的实现原理
- 用户想知道代码为什么要这么写
- 用户要求分析代码的优缺点
- 用户询问代码的优化方向

## 讲解规范

### 1. 文件位置
给出代码的完整文件路径，使用 `file:///` 协议创建可点击链接。

### 2. 核心逻辑
用简洁语言解释这段代码**做了什么**。

### 3. 为什么这么做
分析作者选择这种实现方式的原因，可能包括：
- 业务场景需求
- 技术约束
- 设计模式应用
- 性能考量

### 4. 作用与价值
说明这段代码在整体系统中的角色和贡献。

### 5. 优缺点分析
| 优点 | 缺点 |
|------|------|
| ... | ... |

### 6. 优化方向
提供可行的改进建议，如：
- 性能优化
- 可读性提升
- 错误处理完善
- 设计模式改进

## 输出格式

```markdown
## 📍 文件位置
[完整路径](file:///绝对路径)

## 🎯 核心逻辑
<简明解释>

## 💭 为什么这么做
<原因分析>

## ⚡ 作用与价值
<在系统中的角色>

## ✅ 优点 | ❌ 缺点
| 优点 | 缺点 |
|------|------|
| ... | ... |

## 🚀 优化方向
1. ...
2. ...
```

## 注意事项

- 使用中文回复
- 代码引用使用文件链接
- 保持讲解简洁但全面
- 结合上下文分析代码
- 提供具体可执行的优化建议
